# 보존된 모바일 소스

이 디렉터리는 과거 구현을 보존하기 위한 소스입니다.
현재 TypeScript SDK 지원 대상은 웹 브라우저와 Node.js 백엔드이며, 모바일 앱 SDK는 범위 밖입니다.

- 모바일은 공개 export, TypeScript 빌드, 패키징, lint와 지원 테스트에서 제외됩니다.
- 파일이 남아 있어도 설치 가능한 모바일 모듈이나 현재 Console 연동을 제공한다는 뜻은 아닙니다.
- 서버 앱 비밀키를 모바일 앱에 넣어 연결을 우회하지 마세요.

현재 사용 범위와 연동 한계는 [SDK README](../../README.md)를 참고하세요.
